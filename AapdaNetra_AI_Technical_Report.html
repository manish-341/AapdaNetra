To solve the critical limitation of static machine learning models (which cannot detect rapidly evolving extreme weather events until retrained), Version 3.0 introduces an industry-grade Threshold-Exceedance Dynamic Weather Risk Adjuster. This engine fetches live hyper-local telemetry from the Open-Meteo satellite API, benchmarks current precipitation, temperature, humidity, wind, and root-zone soil moisture against the training data's quantile distribution ($P_{50}, P_{75}, P_{90}, P_{95}, P_{99}$), and dynamically modulates risk probabilities in real time.

3. Machine Learning Methodology & Performance Benchmarks

3.1 Spatial-Aware Cross Validation

Standard random train-test splitting introduces massive artificial inflation (data leakage) in geospatial hazard modeling because neighboring grid cells in the same valley or watershed share identical topography and rainfall. To guarantee true generalization across unseen geographical regions, AapdaNetra implements Spatial-Aware Grouping (StratifiedGroupKFold grouped by district). All records from an entire district are assigned exclusively to either the training set or the test set.

3.2 Platt Scaling Probability Calibration

Raw classification algorithms (particularly tree ensembles) produce uncalibrated probabilities clustered near 0 and 1. To deliver reliable risk percentages to disaster response authorities, each champion model is wrapped with Platt Scaling (Logistic Sigmoidal Calibration via CalibratedClassifierCV(cv="prefit")).

4. Dynamic Weather Risk Adjuster (Threshold-Exceedance Framework)

4.1 The Need for Real-Time Dynamic Adjustment

Terrain and historical precipitation maps represent static susceptibility. However, disaster triggers are dynamic meteorological events:

  • A steep slope in Wayanad with 0.05% baseline risk becomes 90%+ probability when 250 mm of deluge falls in 24 hours.
  • A flood-prone river basin during a severe dry spell does not pose an imminent evacuation threat.

4.2 Live Telemetry Ingestion via Open-Meteo

The service connects in real-time to the Open-Meteo Global Forecasting & Reanalysis API using exact latitude and longitude:

  • temperature_2m (Current ambient temperature, °C)
  • relative_humidity_2m (Ambient humidity, %)
  • precipitation & daily_precipitation_sum (Hourly & 24h accumulated rainfall, mm)
  • wind_speed_10m (Surface wind speed, km/h)
  • soil_moisture_0_to_1cm (Topsoil saturation, m³/m³)

4.3 Mathematical Formulation of Threshold Exceedance

During model training, exact quantile thresholds ($P_{50}, P_{75}, P_{90}, P_{95}, P_{99}$) were computed from the empirical government datasets and stored in JSON. The system maps live weather against these historical percentiles:

1. Exceedance Ratio Calculation:
For any meteorological variable $v$ with current live observation $x$:
$$\text{Exceedance Ratio}(x, v) = \frac{\max(0, x - P_{75}(v))}{P_{95}(v) - P_{75}(v)}$$ (If $x ≤ P_{75}$, ratio is 0. If $x \ge P_{95}$, ratio is 1.0 or higher).

2. Multi-Variable Compound Factor:
$$\text{Exceedance}_{\text{compound}} = 0.6 \times \text{Exceedance}_{\text{primary}} + 0.4 \times \text{Exceedance}_{\text{secondary}}$$ 3. Dynamic Probability Adjustment:
$$\text{Multiplier} = \text{clamp}\left(0.5 + 1.5 \times \text{Exceedance}_{\text{compound}}, \;\; 0.5, \;\; 3.0\right)$$ $$P_{\text{adjusted}} = \text{clamp}\left(P_{\text{base}} \times \text{Multiplier}, \;\; 0.01, \;\; 0.99\right)$$

Behavioral Modes:

  • Severe Storm Surge: Rainfall exceeds $P_{95}$ $\rightarrow$ Multiplier scales up to $3.0\times$.
  • Normal Baseline: Weather near median ($P_{50}$) $\rightarrow$ Multiplier scales near $0.85\times - 1.0\times$.
  • Dry & Favorable: Arid conditions $\rightarrow$ Multiplier dampens down to $0.5\times$.

7. Smart India Hackathon (SIH) Competitive Strengths

  • 100% Genuine Provenance: Evaluators can inspect training code and artifacts to verify zero synthetic generation. Data sources directly link to IMD, CWC, GSI, and NDMA repositories.
  • Spatial Generalization: Spatial-aware validation ensures the model has learned true environmental physics rather than memorizing localized coordinates.
  • Zero-Cost Live Telemetry: Open-Meteo operates with zero API keys and zero cost, ensuring no rate-limiting or credential failures during live judging demonstrations.
  • Robust Fallback Architecture: If the Open-Meteo network request times out, the system automatically falls back to calibrated base ML predictions without throwing 500 errors.
  • Explainable AI (XAI): Each response includes the top mathematical factors driving the prediction, enabling clear operational insights for disaster managers.
